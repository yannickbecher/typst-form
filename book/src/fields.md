# Fields

Every field needs a `name` as its first argument. A dot builds a hierarchy
(`"person.name"`). Fields with the same name are one field: radio groups,
checkbox groups and mirrored copies share their value.

| Function | Page |
|---|---|
| `text-field` | [Text](fields/text.md) |
| `check-box` | [Checkbox](fields/checkbox.md) |
| `radio-group`, `radio-button` | [Radio buttons](fields/radio.md) |
| `combo-box`, `list-box` | [Dropdown and list](fields/choice.md) |
| `push-button`, `submit-button`, `reset-button` | [Buttons](fields/buttons.md) |
| `signature-field` | [Signature](fields/signature.md) |

Options that every field accepts (`required`, `tooltip`, `stroke`, ...) are on
[Options for every field](options.md).

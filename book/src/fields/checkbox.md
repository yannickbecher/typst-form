# Checkbox

```typst
#check-box("newsletter", checked: true, label: [Subscribe])
```

`size: 10pt`, `checked: false`, `export: "Yes"` (value when checked),
`style: "cross"` (`check`, `circle`, `diamond`, `square`, `star`), `label`.

Checkboxes with the same name and different `export` values form a group in
which at most one is checked.

# Viewers

| Viewer | Display | JavaScript (formats, calculations, validation, buttons) |
|---|---|---|
| pdf.js 4.10 (Firefox) | yes | worked in manual checks (no automated viewer test) |
| PDFium (Chrome, Edge) | yes | not tested (Chrome supports only basic scripts) |
| Poppler (Okular, Evince) | yes | none |
| Adobe Acrobat/Reader, Foxit | not tested yet | expected (the `af` functions are Acrobat's own) |

macOS and iOS Preview show the fields but run no JavaScript.
